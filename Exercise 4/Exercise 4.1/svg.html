Exercise 4.1: Draw SVGs

This exercise demonstrates the use of SVG primitives to create and customise a house and garden. The original design is shown beside a modified version to demonstrate changes to position, colour, stroke, grouping and other SVG attributes.

Before

Original house and garden design using basic SVG shapes.

After

Customised house with changes to colours, strokes, shapes and additional garden elements.

Summary of Changes

The following table compares the main elements of the original SVG with the customised version.

Elements Before After
Sun Large yellow circle positioned at (405, 100). Moved to (120, 80) and given an orange stroke.
Sky Plain light-blue rectangular background. Sky colour was changed and clouds were added using <ellipse>.
House Brown rectangle without an outline. Changed to a lighter colour and a dark stroke was added.
Roof Simple orange <polygon>. Roof was enlarged and given a darker outline.
Windows Two simple blue rectangles. Both windows were placed inside a <g> element and positioned using transform="translate()".
Tree Leaves were created using circles. Leaves were changed to ellipses and a stroke was added to the trunk.
Garden Path Thin orange curved paths. Changed to wider beige paths with rounded ends.
Door Plain brown door with black door knob. Added a dark border and changed the door knob to gold.
Additional Elements No clouds, chimney, fence or flowers. Clouds, chimney, flowers and a fence were added to customise the garden.
Text Displays the text "House". Changed to "My Home" with bold text and a different colour.
Coordinates Roof coordinate (150, 205) is annotated. Sun centre coordinate (420, 80) is annotated.

SVG Elements Used

The SVG drawings demonstrate a range of SVG primitives:

  • <rect> — house, door, trunk and background
  • <circle> — sun, leaves and flowers
  • <ellipse> — clouds and modified tree leaves
  • <line> — window details and coordinate annotations
  • <polyline> — garden fence
  • <polygon> — roof
  • <path> — curved garden path
  • <text> — labels and coordinate information
  • <g> — grouping and styling the two windows
